# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters and hiring managers at software companies evaluating Ernesto for developer roles. They scan quickly and verify claims by opening the linked source.

## Product Purpose

A one-page portfolio that turns verified personal projects into interview conversations. Success: the visitor understands "full-stack, interface to database" in seconds, then clicks through to real source.

## Positioning

Evidence-led case studies. Each featured project states problem, what was built, the hard part, stack, and honest personal-project status, with a repository link. Nothing is invented to fill a gap.

## Operating Context

Static page opened in a browser on desktop and phone. No build step, API keys, or paid services. Deployable to Netlify or GitHub Pages.

## Capabilities and Constraints

Four featured projects in a fixed order, a short "also built" list, and email/GitHub contact. Location and availability: "Venezuela · Open to remote". No LinkedIn, resume, live demos, forks, course exercises, or tutorial screens. One WebGL context maximum, with a static fallback. All claims trace to repository source or a user-supplied fact.

## Brand Commitments

Name: Ernesto Donado. Voice: technical-dry, exact, first person, defined in `content.md`. Honesty is binding. The user's binding visual reference for this redesign: an Apple-style page — design, animations, polish.

## Evidence on Hand

`content.md` holds final copy. `docs/superpowers/specs/2026-11-23-portfolio-design.md` holds verified repository claims. Absent and not to be fabricated: metrics, testimonials, clients, live demo links, LinkedIn, résumé.

## Product Principles

Verify every claim. Show evidence over adjectives. One deliberate moment per section. Motion serves feedback and comprehension, never decoration. The page must work without JavaScript or WebGL.

## Accessibility & Inclusion

Reduced-motion and static fallbacks; keyboard-reachable links and controls; visible focus; 44px touch targets; no horizontal scroll from 320px to desktop; readable contrast.
